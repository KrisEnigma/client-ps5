# punktfunk for PlayStation 5

A homebrew title that streams games and desktops from a punktfunk host to a PS5 at up to
3840×2160 and 119.88 Hz: H.264 and HEVC through the console's decoder, PyroWave on the GPU,
the shared console UI on Vulkan, DualSense with rumble and adaptive triggers.

**Status:** code complete through WP4 of `docs/plan.md`; nothing has run on a console yet.
`docs/NOTES.md` lists what each work package still needs a console to prove.

- Tester: `docs/tester.md` is the whole manual.
- Developer: `AGENTS.md`, then `task --list`.

plan WP6 replaces them before the first release (`docs/pins.md`).
